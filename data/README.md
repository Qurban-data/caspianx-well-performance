# Data files

The Equinor Volve production workbook is not included in this repository. Download it from the [Volve data-sharing page](https://www.equinor.com/energy/volve-data-sharing) and either upload the `.xlsx` (or its ZIP archive) in the app or put it here as `Volve production data.xlsx`.

It may not be sold or presented in a misleading or distorted way. The raw workbook is intentionally not committed to this repository. Check the current terms before redistributing it.
