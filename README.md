# Data folder

The raw Volve dataset is **not** included in this repository.

1. Obtain `Volve production data.xlsx` from the Equinor Volve Data Village
   (https://www.equinor.com/energy/volve-data-sharing) or from the Kaggle copy of the same file.
2. Put it in this folder, **or** set the `CASPIANX_DATA` environment variable to its path,
   **or** upload the XLSX (or the original ZIP) inside the app.

Expected sheets: `Daily Production Data` and `Monthly Production Data`.

Licence note: Equinor publishes the Volve data under the *Equinor Open Data Licence* (attribution
required, no resale, no misleading presentation). Check the current terms before redistributing.
